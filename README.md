# InVision U  интеллектуальная система отбора кандидатов

> **Хакатон**: Decentrathon 5.0 | **Трек**: AI inDrive | **Команда**: BLUE NODE

---

## 1. Проблема

InVision U  инновационный университет со 100% стипендиями от inDrive, запущенный в Казахстане для подготовки будущих лидеров, предпринимателей и основателей проектов. При приёме абитуриентов приёмная комиссия сталкивается с серьёзными вызовами.

| Проблема | Последствие |
|----------|-------------|
| Талантливые абитуриенты не умеют продавать себя | Система видит **заявку**, а не **человека** |
| Стандартные формы не выявляют ранние сигналы лидерского потенциала | Сильные кандидаты **самоотсеиваются** ещё до подачи заявки |
| Генеративный ИИ размывает аутентичность мотивационных эссе | Традиционные текстовые форматы становятся **ненадёжными** |
| Качество ручного отбора падает при росте числа заявок | Масштаб и глубина оценки становятся **несовместимы** |

---

## 2. Наше решение

Многоэтапная AIплатформа оценки кандидатов, которая выходит за рамки классического просмотра анкет. Каждый кандидат проходит через несколько слоёв анализа, объединяя структурированные данные, мотивационное эссе, ситуационный тест и помощь интеллектуального ассистента.

```
Путь кандидата (текущее состояние):
/apply > Заполнение формы > AI Nudgeассистент > SJTтест > AIанализ > /status
```

## 3. Текущая реализация

### 3.1 Путь кандидата

#### Форма заявки (`/apply`)

Кандидат заполняет мультиэтапную форму:

- Личные данные, город, университет, GPA
- Список достижений с типом (олимпиада, волонтёрство, проект, награда), уровнем и годом
- Теги навыков
- Загрузка резюме / мотивационного эссе (текст или PDF)

#### AI Nudgeассистент

После заполнения черновика система анализирует содержание и генерирует **35 персонализированных вопросов**, которые помогают кандидату глубже раскрыть свой потенциал. Кандидат отвечает прямо в форме, ответы сохраняются вместе с заявкой.

> **Пример**: кандидат упомянул олимпиаду без деталей  ассистент спрашивает: *Какова была ваша конкретная роль и что вы из этого вынесли?*

Это закрывает ключевую проблему: *Талантливые абитуриенты, не умеющие себя продавать, теряются.*

#### Situational Judgement Test  SJT (`/test`)

4 ситуационных сценария на русском языке в казахстанском контексте:

1. **Кризис лидерства**  конфликт в команде на фоне дедлайна
2. **Этическая дилемма**  обнаружение плагиата перед презентацией
3. **Ограниченные ресурсы**  создание MVP для сельской школы без бюджета
4. **Восстановление после провала**  неудачный демодень стартапа

Оценка по **5 поведенческим осям**: лидерство, решение проблем, командная работа, стрессоустойчивость, этика.

После отправки SJT запускается полный **AIпайплайн**: SJTанализ  эссеанализ  расчёт композитного балла.

#### Личный кабинет кандидата (`/status`)

После подачи заявки кандидат получает доступ к своему личному кабинету, где видит текущий статус заявки и AIоценки по всем измерениям.

---

### 3.2 Панель администратора

#### Дашборд (`/admin`)

Агрегированная аналитика:

- Общее число заявок с разбивкой по статусам
- Среднее значение композитного балла
- Распределение баллов по диапазонам (020, 2040, , 80100)
- Разрез по регионам с выделением сельских кандидатов
- Воронка статусов
- Последние 5 заявок

#### Список кандидатов (`/admin/candidates`)

- Поиск по имени, фильтр по статусу и региону
- Ранжированный список по композитному баллу
- Режим **Blind Mode**  скрывает ФИО и фото для объективной оценки
- Статус **Арбитраж**  для спорных кандидатур
- Детальная карточка: AIрезюме, радарная диаграмма 6 измерений, флаги, достижения, оценки SJT

#### Настройки весов (`/admin/settings`)

Приёмная комиссия настраивает веса 6 AIизмерений прямо в интерфейсе. После сохранения система пересчитывает все композитные баллы.

#### Планировщик интервью (`/admin/scheduler`)

Назначение и управление интервью с кандидатами, включая интеграцию с MiroTalk P2P для видеосвязи.

### 3.3 AIпайплайн

#### Essay Analyzer

**Модель**: Groq API + LLaMA 3.3 70B Versatile

Входные данные: текст эссе, имя, достижения, университет, город.

Выходные данные  структурированный JSON по **6 измерениям**:

| Измерение | Что оценивает | Почему важно |
|-----------|---------------|--------------|
| **Motivation** | Искреннее желание учиться и развиваться | Ключевой предиктор долгосрочного успеха |
| **Leadership** | Инициативность, влияние, готовность брать ответственность | Миссия inVision U  выращивать лидеров |
| **Technical Potential** | Аналитическое мышление, способность решать проблемы | Основа для предпринимательства |
| **Creativity** | Оригинальность мышления, нестандартные подходы | Потенциал к инновациям |
| **Resilience** | Умение преодолевать трудности, пройденный путь | Помогает увидеть бриллиантов в грязи |
| **Social Impact** | Желание приносить пользу обществу | Созвучно социальной миссии inDrive |

Каждому баллу сопоставлен уровень уверенности и цитата из текста. Дополнительно выставляются флаги: `is_ai_generated`, `generic_content`, `high_potential_outlier`.

#### SJT Analyzer

Оценивает развёрнутые ответы на 4 сценария по 5 осям и формирует поведенческий профиль кандидата.

#### AI Nudge Assistant

Анализирует черновик заявки и генерирует персонализированные вопросы через тот же LLM.

#### Achievement Scorer (детерминированный)

| Тип достижения | Баллы |
|----------------|-------|
| Олимпиада  национальная | 20 |
| Олимпиада  региональная | 12 |
| Олимпиада  городская | 8 |
| Волонтёрство | 5 за год (макс. 20) |
| Проект опубликованный / с наградой | 15 |
| Проект обычный | 10 |
| Награда | 8 |

#### Composite Score

```
compositeScore = (weightedAiAverage  scaleFactor) + achievementBonus + ruralBonus
```

- **weightedAiAverage**  взвешенное среднее по 6 AIизмерениям (веса из настроек)
- **achievementBonus**  детерминированные баллы (с потолком)
- **ruralBonus**  +5 баллов для кандидатов из недопредставленных регионов

### 3.4 Честность и объяснимость

**HumanintheLoop**: ИИ никогда не принимает финальное решение. Система выдаёт баллы и обоснования  человек принимает решение.

**Снижение предвзятости**:

- Ruralбонус для абитуриентов из Кызылорды, Атырау, Актау, Туркестана и других регионов
- Измерение Resilience фокусируется на траектории роста, а не только на ресурсах
- Промпту ИИ явно запрещено учитывать пол, этничность и доход как негативные сигналы
- Blind Mode скрывает идентификаторы при первичном просмотре

**Аудит**: каждое изменение статуса, пересчёт баллов и действие администратора фиксируется в `audit_log` с временной меткой.

## 4. Быстрый старт

### Требования

- Node.js 18+
- Docker и Docker Compose
- Groq API key (бесплатно: [console.groq.com](https://console.groq.com))

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Mountygoi/InVision-U.git
cd InVision-U

# 2. Запустить PostgreSQL
docker compose up -d

# 3. Сервер
cd server
npm install
# Создать .env (см. ниже)
npm run dev          # http://localhost:5000

# 4. Клиент (новый терминал)
cd client
npm install
npm run dev          # http://localhost:5173
```

### Переменные окружения (`server/.env`)

```env
GROQ_API_KEY=gsk_xxxxx
DB_HOST=127.0.0.1
DB_PORT=5433
DB_NAME=invision_u
PORT=5000
```

## 6. Планируемые улучшения

> Следующие функции запланированы к реализации на следующем этапе разработки.

### 6.1 Тест личности (Personality Test)

Восьмикластерный психологический опросник  научно обоснованный инструмент оценки черт личности, встроенный в путь кандидата между SJT и итоговым анализом.

**8 кластеров оценки:**

| Кластер | Что измеряет |
|---------|--------------|
| **Leadership Initiative** | Склонность брать инициативу и вести за собой |
| **Responsibility** | Готовность отвечать за результат |
| **Growth Mindset** | Установка на рост и постоянное обучение |
| **Ambition** | Целеустремлённость и стремление к высоким результатам |
| **Ethics** | Моральные принципы и справедливость |
| **Community Orientation** | Ориентация на помощь людям и сообществам |
| **Collaboration** | Способность к эффективной командной работе |
| **Critical Thinking** | Аналитическое и критическое мышление |

Для каждого кластера  5 вопросов по шкале Лайкерта. Результат: нормализованные баллы (0100) и нарративный портрет личности от LLM.

---

### 6.2 Командная симуляция (Team Simulation)

Интерактивная ролевая симуляция: кандидат на **5 обменов** управляет кризисной ситуацией в команде из трёх AIагентов.

**Сценарий**: студенческая волонтёрская команда организует бесплатные курсы для детей. До презентации перед спонсором  48 часов. Внезапно возникает кризис.

| Агент | Характер |
|-------|----------|
| **Айгерим** | Перегружена домашними обстоятельствами, не успевает, чувствует себя виноватой, просит о помощи косвенно |
| **Даурен** | Самоуверенный, хочет кардинально изменить формат проекта в последний момент, давит своим мнением |
| **Нурлан** | Выгоревший, апатичный, отвечает односложно (ок, не знаю), открывается только при искреннем участии |

Каждый агент управляется отдельным LLMпромптом и не раскрывается легко. После симуляции AI оценивает поведение кандидата по **5 осям**:

- Лидерство
- Эмпатия
- Управление конфликтами
- Командная ориентация
- Принятие решений

Дополнительно определяется **стиль лидерства**: `authoritative / facilitative / democratic / passive`.

## 7. Принципы разработки

### Без чёрных ящиков

Каждое AIрешение сопровождается цитатами, уровнем уверенности и объяснением. Приёмная комиссия понимает, *почему* кандидат получил тот или иной балл.

### Человек принимает решение

ИИ предоставляет данные и рекомендации. Финальный шаг  всегда за человеком. Все действия фиксируются в аудитлоге.

### Справедливость как функция системы

Ruralбонус, Blind Mode, измерение Resilience  это не настройки, а встроенные механизмы снижения системных барьеров.

## 8. Известные ограничения (текущий прототип)

- Пароли хранятся в открытом виде  в продакшене необходим bcrypt
- Нет rate limiting на API  в продакшене нужен expressratelimit
- Нестабильность LLM: одно эссе может получать чуть разные баллы при повторном вызове
- PDFпарсинг может некорректно обрабатывать сложные макеты
- Промпты написаны на русском; казахский язык может снижать точность оценок
