# InVision U

> **Хакатон**: Decentrathon 5.0 | **Трек**: AI inDrive | **Команда**: BLUE NODE

AI-платформа для многоэтапного отбора стипендиатов. Система помогает приёмной комиссии оценивать кандидатов объективно и глубоко — через анализ эссе, ситуационные тесты, тест личности, командную симуляцию и единый рейтинг.

🌐 **Демо**: [invision-u.ondigitalocean.app](https://invision-u.ondigitalocean.app)

---

## Проблема

| Что происходит | К чему приводит |
|----------------|-----------------|
| Талантливые абитуриенты не умеют подать себя | Комиссия видит **анкету**, а не **человека** |
| Стандартные формы не выявляют лидерский потенциал | Сильные кандидаты **теряются** ещё до подачи |
| ChatGPT пишет эссе за кандидатов | Мотивационные письма становятся **ненадёжными** |
| Ручная проверка сотен заявок | Качество отбора **падает** с ростом потока |

---

## Решение

Каждый кандидат проходит 6 этапов оценки. На каждом этапе ИИ помогает раскрыть потенциал глубже, чем это возможно при ручном просмотре.

```
Заявка → AI Nudge → Личность → SJT → Симуляция → Рейтинг
```

## Путь кандидата

### 1. Заявка (`/apply`)

Мультиэтапная форма:
- Личные данные: имя, школа, город, пол, контакты (Telegram/WhatsApp)
- Достижения: олимпиады, проекты, волонтёрство, награды (тип + уровень + год)
- Навыки: теги из списка или свои
- Эссе: мотивационный текст
- Документы: IELTS-сертификат, сертификат ҰБТ, аватар
- Баллы IELTS и ҰБТ
- Видеовизитка: ссылка на YouTube или Google Drive

### 2. AI Nudge-ассистент

После заполнения черновика ИИ анализирует заявку и генерирует **3–5 персонализированных вопросов**, чтобы помочь кандидату раскрыться лучше. Ответы сохраняются и учитываются при финальном анализе.

> **Пример**: кандидат упомянул олимпиаду без деталей → ассистент спрашивает: *«Можешь привести один пример, где ты использовал этот навык на практике?»*

После ответов система оценивает **обучаемость (coachability)** кандидата — 6 измерений: обучаемость, лидерский потенциал, путь роста, аутентичность, вовлечённость, самоосознание.

### 3. Тест личности (`/personality`)

40 вопросов по шкале Ликерта → **8 кластеров**:

| Кластер | Что измеряет |
|---------|--------------|
| Leadership Initiative | Склонность брать инициативу |
| Responsibility | Готовность отвечать за результат |
| Growth Mindset | Установка на развитие |
| Ambition | Целеустремлённость |
| Ethics | Моральные принципы |
| Community Orientation | Ориентация на помощь другим |
| Collaboration | Командная работа |
| Critical Thinking | Аналитическое мышление |

Баллы рассчитываются детерминистически (0–100). LLM генерирует краткий нарративный портрет личности.

### 4. Ситуационный тест — SJT (`/sjt`)

4 реалистичных сценария на русском языке:

1. **Кризис лидерства** — конфликт в команде на фоне дедлайна
2. **Этическая дилемма** — обнаружение плагиата перед презентацией
3. **Ограниченные ресурсы** — создание MVP без бюджета и с плохим интернетом
4. **Восстановление после провала** — неудачный демо-день стартапа

Кандидат выбирает вариант ответа **и объясняет свой выбор**. ИИ оценивает по 5 осям: лидерство, решение проблем, командная работа, стрессоустойчивость, этика.

### 5. Командная симуляция (`/simulation`)

Интерактивная ролевая симуляция: кандидат руководит командой из 3 AI-агентов в кризисной ситуации.

**Сценарий**: студенческая волонтёрская команда организует курсы для детей. До презентации перед спонсором — 48 часов. Каждый участник — проблемный:

| Агент | Характер |
|-------|----------|
| **Айгерим** | Перегружена, не успевает, чувствует вину, намекает на помощь, но не просит напрямую |
| **Даурен** | Самоуверенный, хочет всё переделать в последний момент, давит своим мнением |
| **Нурлан** | Выгоревший, отвечает односложно, открывается только при искреннем участии |

Кандидат пишет минимум 5 сообщений. Каждый агент управляется отдельным LLM-промптом и реагирует реалистично.

После симуляции ИИ оценивает: лидерство, эмпатию, управление конфликтами, командную ориентацию, принятие решений. Определяется стиль лидерства: `authoritative / facilitative / democratic / passive`.

### 6. Личный кабинет (`/status`)

Кандидат входит по email и паролю. Видит:
- Текущий статус заявки
- AI-оценки по всем пройденным этапам
- Назначенное интервью (если есть)

## Панель администратора

### Дашборд (`/admin`)

- Общее число заявок с разбивкой по статусам
- Среднее значение композитного балла
- Распределение баллов по диапазонам
- Воронка статусов
- Последние заявки

### Список кандидатов (`/admin/candidates`)

- Поиск по имени, фильтр по статусу
- Ранжирование по композитному баллу
- **Blind Mode** — скрывает ФИО и фото для объективной оценки
- **Арбитраж** — отдельный статус для спорных кандидатур с повторным AI-анализом
- Детальная карточка: AI-резюме, радарная диаграмма, флаги, достижения, все оценки
- Ревью: техническая и софт-оценка вручную, комментарии

### Настройки весов (`/admin/settings`)

Комиссия настраивает веса AI-измерений через интерфейс. После сохранения все композитные баллы пересчитываются автоматически.

### Планировщик интервью (`/admin/scheduler`)

Назначение интервью с указанием даты/времени. Видеосвязь через встроенный MiroTalk (WebRTC).

## AI-пайплайн

Платформа использует **6 AI-анализаторов**, работающих через Groq Cloud API (LLaMA 3.3 70B Versatile).

### Essay Analyzer

Оценивает мотивационное эссе по 6 измерениям (0–100):

| Измерение | Что оценивает |
|-----------|---------------|
| Motivation | Искреннее желание учиться и развиваться |
| Leadership | Инициативность, влияние, ответственность |
| Technical Potential | Аналитическое мышление, решение проблем |
| Creativity | Оригинальность мышления |
| Resilience | Умение преодолевать трудности |
| Social Impact | Желание приносить пользу обществу |

Каждому баллу сопоставлен уровень уверенности и цитата из текста. Дополнительно: флаги `is_ai_generated`, `generic_content`, `high_potential_outlier`.

### SJT Analyzer

Анализирует ответы на 4 сценария по 5 осям и формирует поведенческий профиль.

### Personality Analyzer

Детерминистический расчёт 8 кластеров + LLM-нарратив.

### Simulation Analyzer

- **Генерация ответов агентов** — отдельный промпт для каждого персонажа
- **Анализ лидерства** — оценка поведения кандидата по 5 измерениям + определение стиля

### Nudge Analyzer

Генерирует 3–5 персонализированных вопросов на основе черновика заявки.

### Learnability Analyzer

Оценивает обучаемость: как изменилось качество заявки после AI-подсказок. 6 измерений: coachability, leadershipPotential, growthTrajectory, authenticity, engagement, selfAwareness.

### Achievement Scorer (детерминированный)

| Тип достижения | Баллы |
|----------------|-------|
| Олимпиада — национальная | 20 |
| Олимпиада — региональная | 12 |
| Олимпиада — городская | 8 |
| Волонтёрство | 5 за каждый год (макс. 20) |
| Проект с наградой / опубликованный | 15 |
| Проект обычный | 10 |
| Награда | 8 |

### Composite Score

Единый рейтинг кандидата, рассчитываемый из всех источников:

```
compositeScore =
    weightedEssayAverage × essayFactor
  + personalityScore × personalityFactor
  + simulationScore × simulationFactor
  + achievementBonus
```

Все коэффициенты настраиваются через Admin Settings без изменения кода.

## Честность и объяснимость

- **Human-in-the-Loop**: ИИ не принимает финальных решений. Он предоставляет баллы и обоснования — решает человек
- **Blind Mode**: скрывает ФИО и фото при первичном просмотре
- **Флаг AI-генерации**: система детектирует тексты, написанные ChatGPT
- **Аудит**: каждое изменение статуса, пересчёт баллов и действие администратора фиксируется в `audit_log`

## Быстрый старт

### Требования

- Node.js 18+
- Docker и Docker Compose
- Groq API key (бесплатно: [console.groq.com](https://console.groq.com))

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Mountygoi/InVision-U.git
cd InVision-U

# 2. Запустить PostgreSQL
docker compose up -d

# 3. Сервер
cd server
npm install
# Создать .env (см. ниже)
npm run dev          # http://localhost:5000

# 4. Клиент (новый терминал)
cd client
npm install
npm run dev          # http://localhost:5173
```

### Переменные окружения (`server/.env`)

```env
GROQ_API_KEY=gsk_xxxxx
DB_HOST=127.0.0.1
DB_PORT=5433
DB_NAME=invision_u
DB_USER=invision
DB_PASSWORD=invision_pass
PORT=5000
```

### Тесты

```bash
# Серверные тесты (33 теста)
cd server && npm test

# Клиентские тесты (31 тест)
cd client && npm test
```
